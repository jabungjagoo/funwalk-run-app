# 🏃 FUN WALK & RUN  - Vibrant Light Edition

Aplikasi pendaftaran dan pelaporan aktivitas Fun Walk & Run

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)
![Status](https://img.shields.io/badge/status-active-success)

## ✨ Fitur Utama

- 📝 **Form Pendaftaran** - Input data peserta dengan validasi
- 📸 **Upload File** - Upload bukti aktivitas dan selfie
- 🎨 **Animasi Interaktif** - Desain vibrant dengan animasi dinamis
- 📱 **Responsive Design** - Tampilan optimal di semua perangkat
- 📊 **Google Sheets Integration** - Data tersimpan otomatis
- ☁️ **Google Drive Integration** - File upload tersimpan di Drive

## 🚀 Teknologi

| Teknologi | Kegunaan |
|-----------|----------|
| **HTML5 + CSS3** | Struktur dan styling |
| **Tailwind CSS** | Framework CSS untuk desain cepat |
| **Google Apps Script** | Backend API dan integrasi Google |
| **GitHub Pages** | Hosting frontend (cepat!) |
| **Google Sheets** | Database penyimpanan data |
| **Google Drive** | Penyimpanan file upload |

## 📊 Struktur Data

Data yang tersimpan di Google Sheets:

| Kolom | Deskripsi |
|-------|-----------|
| Timestamp | Waktu pengiriman data |
| Email | Email peserta |
| Nama | Nama lengkap peserta |
| Payroll | ID Payroll |
| No HP | Nomor handphone |
| Departemen | Departemen/divisi |
| Jenis Aktivitas | FUN WALK / FUN RUN |
| Setoran Ke | Hari ke berapa |
| Tanggal | Tanggal aktivitas |
| Waktu | Waktu aktivitas |
| Jarak (KM) | Jarak tempuh |
| Waktu Tempuh (Menit) | Durasi aktivitas |
| URL Bukti | Link file bukti di Drive |
| URL Selfie | Link file selfie di Drive |
